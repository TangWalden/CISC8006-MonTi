# Frozen-author block recipient selection

This registered follow-up keeps the author's original MonTi output as the
upstream. A completed single-edge study was null: native and learned mean
GAGA MR both 57.9101%, versus 57.8517% matched random. A model-free follow-up
found unchanged added-neighbor memberships for 455 of 669 target occurrences
in activated learned cases. This identifies a structural limitation, not the
sole explanation for failed transfer.

The downstream changes one **whole candidate column**: remove every injected
attachment to an outcome-blind donor candidate, and attach those same rows
to one eligible recipient. Multi-row donors are preferred when feasible.
All generated features, target edges, injected-to-injected edges, individual
injected degrees and total budgets stay fixed. No author regeneration or
upstream training occurs; all 576 parent captures are reused by hash.

Only the recipient is learned, using the same 32 descriptors as the prior
study averaged across affected rows, with the same TRAIN-only ridge fit and
gain threshold. Eight recipients are sampled before outcomes. The matched
random arm uses **the exact same donor, removed rows, activation and edge
count**. This isolates recipient choice within this block policy. An always
random arm is auxiliary and cannot be selected as an improved model.

Three cached noise repetitions share one author checkpoint. The complete
128 TRAIN/64 VALID cohort is retained, including infeasible/abstained cases.
All decisions are sealed before official GAGA scoring. Qualification requires
positive differences in all three repeats and a positive nominal paired-t
lower bound against both native and matched random. Development has been
reused; intervals do not correct adaptive search. No TEST access is allowed.

The frozen protocol binds source, inputs, CPU cost caps and saved-only audits.
The [completed result](../../results/block_swap/) is null: learned and native
57.9101% MR, matched random 57.9685%. No efficacy or first-novelty claim.
