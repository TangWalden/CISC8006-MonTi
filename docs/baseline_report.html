MonTi candidate selection: component reproduction

Junyi Tang / Yifan Fan · CISC8006 · Baseline evidence report

Conclusion: inconclusive

Learned selection: 43.73 ± 0.75% MR; random selection: 40.19 ± 1.30% (sample standard deviation, three seeds). Mean paired difference: +3.54 percentage points; paired Student t 95% interval: [−1.54, 8.62]. The pre-registered rule therefore does not establish a positive effect. No additional seeds were added to seek significance.

Frozen setting and metric

GossipCop-S, split 0; fixed official GCN surrogate and GAGA victim; rho=0.05, xi=0.1; K=128; maximum 100 epochs, patience=10; paired seeds 0/1/2. Attackers are retrained separately. Clean MR is 21.6833%, matching the paper's 21.68% at its displayed precision.

MR is total incorrect target-node occurrences divided by total target-node occurrences across groups. Overlapping nodes count within each group. Higher MR means a stronger attack. Training/validation/test groups: 937/592/909; the test denominator is 10,515 occurrences.

The graph has 16,488 nodes, 768 features, and 3,865,058 undirected non-self edges. DGL stores 7,746,604 directed arcs including both directions and 16,488 self-loops.

Paper comparison and limitations

  1. Paper Table 5 reports 43.70% / 39.13%, a 4.57pp difference. Table 4 reports 41.34 ± 1.90% for the corresponding MonTi setting; this discrepancy remains unresolved.
  2. The configuration flag passed to cand_selection had reversed semantics. The minimal mapping fix is tested, but it does not prove that historical paper experiments or released checkpoints used reversed conditions.
  3. The defined random control resamples uniformly without replacement at each training and evaluation forward pass from the same non-target exploration pool. Historical Table 5 sampling semantics are unconfirmed.
  4. The upstream incidence-based neighbor budget is retained consistently in both arms, despite a difference from the paper's unique-neighbor set definition.
  5. The interval covers only run randomness under one split and fixed detectors. Shared GPU timing is descriptive and does not reproduce an efficiency claim.

Evidence and remaining work

See registered runs, independent audit, group error counts, and training logs. Failed setup and test attempts are retained. Large models, data, and original node-level predictions remain outside Git with hashes recorded.
